# 📜 User Task Script — ข้อกำหนดและโจทย์การทดสอบสำหรับผู้ใช้

## 🎯 Task Scenarios (สำหรับผู้ร่วมทดสอบ)
1. **Task 1 (Data Fetching):** ให้ผู้ใช้เปิดหน้าหลักและเลื่อนสำรวจรายการอาหาร (ระบบจะเรียกใช้ API ดึงเมนูจาก Database)
2. **Task 2 (Data Submission):** ให้ผู้ใช้เลือกเมนูอาหารที่ต้องการ ใส่รายละเอียด และกด "ยืนยันการสั่งอาหารล่วงหน้า"
3. **Task 3 (Real-time Sync):** ให้ผู้ใช้ไปที่หน้าประวัติการสั่งซื้อ เพื่อตรวจสอบว่าระบบแสดงผลรายการออเดอร์และเวลาได้ถูกต้องแม่นยำหรือไม่
